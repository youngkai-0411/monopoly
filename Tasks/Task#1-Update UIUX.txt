# TASK — TỐI ƯU UI/UX GAME “TỶ PHÚ VIỆT NAM”

Bạn đang tiếp tục phát triển Web Board Game **Tỷ Phú Việt Nam**.

Game hiện đã có giao diện Isometric Board hoạt động và visual direction tương đối tốt. Nhiệm vụ lần này **KHÔNG phải redesign toàn bộ game**, mà là tối ưu UI/UX màn hình gameplay hiện tại, đặc biệt cho **Mobile Landscape**.

---

# 1. MỤC TIÊU CHÍNH

Giao diện hiện tại đang có cảm giác:

> “Game nằm bên trong một dashboard.”

Mục tiêu mới:

> “Người chơi đang trực tiếp ở trên bàn cờ.”

Board phải trở thành thành phần quan trọng nhất trên màn hình.

Ưu tiên:

**Game World > Gameplay Actions > Secondary Information**

Không để các panel UI chiếm quá nhiều diện tích của Board.

# 7. PROPERTY CONTEXT CARD

Khi:

- Player tap Property;
- Token vừa đáp xuống Property;
- Property cần interaction;

thì hiển thị Context Card.

Ví dụ:

```text
┌────────────────────────┐
│ 📍 HỒ CHÍ MINH         │
│                        │
│ 🏛️ Chợ Bến Thành      │
│                        │
│ Owner      Nghĩa       │
│ Level      Lv.1        │
│ Giá        120 Tr      │
│ Rent        20 Tr      │
│                        │
│ [ XEM CHI TIẾT ]       │
└────────────────────────┘
```

Nếu Property chưa có chủ:

```text
HỒ CHÍ MINH

Giá
120 Tr

Rent
20 Tr

[ MUA 120 TR ]

Bỏ qua
```

Ưu tiên Bottom Sheet trên màn hình nhỏ.

Context Card không được permanently chiếm board space.


# 12. PHASE — MOVING

Sau khi dice result xuất hiện:

```text
🎲 2 + 🎲 3

= 5

Đang di chuyển...
```

Trong lúc token movement:

- Disable Roll.
- Disable End Turn.
- Disable Buy.
- Disable Upgrade.
- Disable conflicting UI interactions.

Engine vẫn phải validate phase, không chỉ disable button.

---

# 13. PHASE — RESOLVE PROPERTY

Ví dụ:

```text
HỒ CHÍ MINH

Giá: 120 Tr

[ MUA ]

[ BỎ QUA ]
```

Hoặc nếu đã mua:

```text
✓ ĐÃ MUA HỒ CHÍ MINH

-120 Tr
```

Sau khi resolve hoàn tất mới cho phép:

```text
[ KẾT THÚC LƯỢT ]
```

# 27. TOUCH UX

Phải ngăn:

- accidental text selection;
- double tap zoom nếu gây vấn đề;
- long press menu;
- repeated action;
- dragging ngoài ý muốn.

Áp dụng phù hợp:

```css
user-select: none;
-webkit-user-select: none;
-webkit-touch-callout: none;
touch-action: manipulation;
```

Không disable browser accessibility một cách không cần thiết.
