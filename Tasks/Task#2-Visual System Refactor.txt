# TASK — VISUAL SYSTEM V3
## Tỷ Phú Việt Nam — Visual Polish, Typography & Design System

Bạn đang tiếp tục phát triển Web Board Game **“Tỷ Phú Việt Nam”**.

Project hiện đã có:

- Gameplay screen.
- Three.js Isometric Board.
- Low-poly environment.
- Player HUD.
- Contextual Action UI.
- Property UI.
- Camera controls.
- Dice.
- Player tokens.
- Mobile Landscape support.
- Visual style hiện tại được mô tả trong file `visual-style-reference.md`.

Hãy đọc kỹ:

`visual-style-reference.md`

và audit implementation thực tế trước khi sửa code.

---

# 1. MỤC TIÊU

Task này KHÔNG phải redesign game từ đầu.

Mục tiêu là nâng visual system hiện tại thành một hệ thống:

- dễ đọc hơn;
- rõ hierarchy hơn;
- nhất quán hơn;
- thân thiện với Mobile Landscape;
- có cảm giác board game chuyên nghiệp hơn;
- vẫn giữ personality hiện tại;
- giảm cảm giác “web dashboard”;
- giữ identity Việt Nam hiện đại, thân thiện.

Visual direction cần giữ:

> Modern Vietnamese Travel / Property Board Game

Các đặc điểm chính:

- Isometric.
- Low-poly.
- Soft.
- Warm.
- Friendly.
- Colorful nhưng không quá saturated.
- Cream + Teal + Gold UI.
- Vietnamese travel identity.

# 5. SEMANTIC COLOR RULES

Sau refactor, màu phải có ý nghĩa rõ ràng.

## GOLD

Gold chỉ dùng cho:

> PRIMARY GAMEPLAY ACTION

Ví dụ:

- Đổ xúc xắc.
- Mua.
- Nâng cấp.
- Xác nhận.
- Kết thúc lượt khi đây là primary action.

Nguyên tắc:

> Thấy Gold → đây là action chính tiếp theo.

Không sử dụng Gold quá nhiều cho decoration.

---

## DARK TEAL

Dark Teal dùng cho:

> ACTIVE / SELECTED / NAVIGATION STATE

Ví dụ:

- Follow Camera đang active.
- Tab đang selected.
- Toggle active.
- Navigation selection.

Không sử dụng Gold cho những trạng thái này.

---

## RED

Red dùng cho:

> DANGER / ERROR / DESTRUCTIVE ACTION

Ví dụ:

- Error.
- Bankruptcy warning.
- Destructive confirmation.
- Không đủ tiền nếu cần cảnh báo.

Chuẩn hóa error colors hiện tại thành một semantic family.
