# TASK — AUDIT 3D VISUAL SYSTEM
## Tỷ Phú Việt Nam — 3D Palette, Materials, Lighting & Readability

Bạn đang tiếp tục phát triển Web Board Game **“Tỷ Phú Việt Nam”**.

Visual System V3 cho phần UI đã được hoàn thành.

Bước tiếp theo là đánh giá:

> **3D Palette + Materials + Lighting + Gameplay Readability**

## QUAN TRỌNG

Task này **CHỈ LÀ AUDIT**.

KHÔNG:

- thay đổi màu;
- chỉnh material;
- chỉnh lighting;
- chỉnh Three.js scene;
- chỉnh camera;
- chỉnh Game Engine;
- chỉnh gameplay;
- refactor renderer;
- tự quyết định palette mới.

Mục tiêu duy nhất:

> Đọc source hiện tại và tạo một tài liệu mô tả chính xác hệ thống visual 3D đang được sử dụng.

Output chính:

`3d-visual-reference.md`
